# 00 · Overview

This methodology describes how long-term capital-market assumptions (LTCMA) are
formed and turned into a target allocation. It is written to be read on its own:
each section states *what* is assumed and *why*, leaving the numerical derivation
(which lives in a private workbook) out of scope.

The four parts:

1. **[Assumptions](01_assumptions.md)** — the expected return, volatility, and
   correlation inputs, and the reasoning behind each.
2. **[Allocation framework](02_allocation_framework.md)** — how the assumptions map
   to portfolio weights.
3. **[Rebalancing rules](03_rebalancing_rules.md)** — when and how the allocation is
   brought back to target.
